# 직접 설치하는 앱

Homebrew와 App Store에 없어서 `apps-sync`가 설치하지 못하는 앱이다. 새 맥에서는 직접 받는다.

| 앱 | 받는 곳 | 비고 |
|---|---|---|
| Atlas (`dev.atlas.ide`) | 배포처에서 받은 dmg | ChatGPT Atlas 브라우저와 다른 앱 |
| Adobe Illustrator 2026 | Creative Cloud 앱 | `adobe-creative-cloud` 설치 후 |
| Photon Studio (`com.tenzen.photon`) | 배포처에서 받은 dmg | |

## 목록에 넣지 않는 것

다른 앱이 함께 깔아 주는 앱이라 따로 적지 않는다.

- Google Docs·Google Sheets·Google Slides: `google-drive`
- Karabiner-EventViewer·.Karabiner-VirtualHIDDevice-Manager (Karabiner-Elements 포함): `karabiner-elements`
- Microsoft Defender Shim: Microsoft 365 설치 시 따라 들어옴

회사 VPN(Cisco AnyConnect)은 회사가 배포하는 설치 파일로 깐다.

은행·공공 사이트가 필요할 때 알아서 설치하는 보안 프로그램(AhnLab ASTx, Delfino, Veraport, TouchEn nxKey, INISAFE CrossWeb, SoftForum)은 맥마다 맞출 필요가 없어서 뺀다.
